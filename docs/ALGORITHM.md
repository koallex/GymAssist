# Алгоритм генерации программы

Кратко, без привязки к UI.

## Вход

`UserProfile`: уровень, цель, дни/неделю, длительность сессии, оборудование, ограничения (суставы), исключённые упражнения, опционально приоритетные мышцы (только advanced).

## Шаги

1. **Нормализация и валидация** профиля (`normalizeProfile`, `validateProfile`). Возраст &lt; 18 → ошибка.
2. **Сплит** (`chooseSplit`): 2–6 дней с учётом уровня, цели и `preferredFormat` (auto / full_body / upper_lower / ppl).
3. **Недельные цели объёма** по каждой из 14 мышечных групп: таблица уровня × цель × поправка возраста × специализация.
4. **Распределение** целевого объёма по дням, где мышца встречается в сплите.
5. **Подбор упражнений** на день:
   - сначала compound, затем isolation по шаблонам паттернов (`MUSCLE_SLOTS`);
   - паттерны ротируются между днями;
   - косвенная нагрузка от уже выбранных движений уменьшает остаток объёма (с потолком);
   - фильтр по оборудованию, сложности, травмам, исключениям.
6. **Подгонка под время** сессии: сокращаются изоляция и мелкие группы в последнюю очередь; крупная группа не выкидывается из всех дней сразу.
7. **Недельный объём и предупреждения** (`computeWeeklyVolume`, notes/warnings).
8. **Правило прогрессии** (double progression) кладётся в план как рекомендация.

## Замена упражнения

`getAlternatives` / `replaceExercise`: та же primary-мышца, предпочтение того же или близкого паттерна, пересчёт повторений/отдыха, структура дня и число подходов сохраняются.

## Конфиг

Все числа (объёмы, повторения, отдых, лимиты, age adjustments) — в `src/lib/config.ts` (`CONFIG_VERSION`). Логику генератора можно не трогать при тонкой настройке.


## Рекомендованный вес (`loadEstimator`)

Нужен только как безопасная **точка старта**; после первой записанной тренировки вес берётся из фактических результатов.

1. Опорная масса = фактический вес, но не выше массы при ИМТ 27 (`LOAD.bmiCap`): избыточная жировая масса силу не добавляет. Здесь используется рост.
2. 1ПМ ≈ опорная масса × базовое отношение упражнения (`LOAD_RATIO`, для нетренированного мужчины) × множитель уровня × множитель пола (верх/низ) × множитель возраста.
3. Рабочий вес = 1ПМ / (1 + (повторения + запас) / 30) — формула Эпли; повторения и запас берутся из плана (нижняя граница диапазона и `targetRIR`, то есть цель влияет через план).
4. × 0,85 (коэффициент безопасности первой оценки) и × 0,9, если в анкете указаны травмы/ограничения. Упражнения, нагружающие указанные суставы, и так исключаются генератором.
5. Округление до реального шага оборудования: штанга 2,5 кг (минимум — гриф 20 кг), гантели 1/2/2,5 кг по диапазонам, блоки и тренажёры 2,5 кг.

Для «пол не указан» взяты осторожные (женские) множители. Свой вес, статика и тренажёр с помощью числового веса не получают. Если расчёт меньше минимума снаряда, пользователь видит пояснение.

## Адаптация по итогам тренировок (`progressionEngine`)

Адаптация **вычисляется заново** из (план + история) и не меняет сохранённый план, поэтому детерминирована и проверяется тестами. История проигрывается в хронологическом порядке отдельно по каждому упражнению.

| Событие | Реакция |
|---|---|
| Все подходы на верхе диапазона, тренировка выполнена полностью, не «тяжело» | Счётчик +1; при достижении порога (`sessionsAtTopToProgress`: 1 / 2 / 2 по уровням) вес растёт на шаг |
| «Было легко», все подходы выполнены, повторы не ниже середины диапазона | Прибавка веса сразу |
| «Тяжело» | Вес сохраняется, прогресс не засчитывается |
| «Слишком тяжело» | Вес −10% (`ADAPT.deloadTooHard`) |
| Не хватило повторов у нижней границы в половине подходов и больше | Вес −5% |
| Не выполнено полностью | Вес сохраняется |
| Дискомфорт в суставе | Вес −10% в упражнениях на этот сустав, предупреждение, предложение добавить ограничение и пересчитать программу |
| Пользователь изменил вес сам | Новая точка отсчёта (используется фактический вес, медиана по выполненным подходам) |

Объём (глобально, по цепочке тренировок): «слишком тяжело» или «не до конца» → временно −1 подход у ~⅓ упражнений дня (сначала изолирующие, не ниже 2 подходов), отдых +15 с, запас повторений +1; тренировка «в самый раз»/«легко» в полном объёме возвращает план. Недельный объём пересчитывается по скорректированным дням.

## Опора на источники

Числовые значения — ориентиры в `config.ts` и `loadConfig.ts`; их можно менять без правки логики.

- ACSM Position Stand (2026), Currier et al., *Medicine & Science in Sports & Exercise*: индивидуализация нагрузки и объёма, все крупные группы мышц не реже 2 раз в неделю, для силы — тяжёлые нагрузки (около 80% 1ПМ) в 2–3 подходах, для гипертрофии — порядка 10 подходов на группу в неделю, тренировка до отказа и сложная периодизация не обязательны.
- WHO, Guidelines on physical activity and sedentary behaviour: общие рекомендации, включая силовые упражнения на основные группы мышц не менее 2 дней в неделю.
- NSCA (определение частоты силовых тренировок) и BJSM (систематический обзор с байесовским сетевым метаанализом): использовать для уточнения частоты и сравнения схем; их положения в параметры пока **не переносились** — нужно сверить с полными текстами.
