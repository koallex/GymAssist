# Gym Assistant — этапы 1–5

Персональный виртуальный тренер для тренажёрного зала.

## Запуск

```bash
npm install
npm test
npm run typecheck
npm run dev
```

http://localhost:3000 — при первом запуске откроется полная анкета.

## Реализовано

### Этапы 1–2 — ядро
- Детерминированный `generateProgram`
- 74 упражнения, сплиты 2–6 дней
- Замена упражнений
- 95 автотестов

### Этапы 3–4 — интерфейс + полная анкета
- **Полная анкета**: пол, возраст/рост/вес, уровень, цель, дни, длительность, оборудование, травмы/ограничения
- localStorage (профиль + программа)
- Dashboard, «Моя программа» с заменой упражнений
- Профиль с редактированием всех параметров и пересчётом

### Этап 5 — библиотека
- Поиск по названию
- Фильтры: мышечная группа, оборудование, сложность
- Карточка упражнения: SVG-схема, техника, вторичные мышцы, оборудование
- SVG-иллюстрации (единый стиль, подсветка зоны по группе мышц)
- Иллюстрации также в списке упражнений программы

## Структура

```
src/
  app/
    onboarding/     # Полная анкета
    program/        # Программа + замена
    library/        # Библиотека + [id]
    profile/        # Профиль
    progress/       # (этап 6–7)
  components/
    onboarding/     # OnboardingWizard
    exercises/      # ExerciseIllustration (SVG)
    layout/         # AppShell, BottomNav
    ui/
  lib/              # Ядро без React
```
