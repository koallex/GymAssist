# Gym Assistant — этапы 1–7

Персональный виртуальный тренер для тренажёрного зала.

## Запуск

```bash
npm install
npm test
npm run typecheck
npm run dev
```

## Реализовано

### 1–2 Ядро
Детерминированный генератор, 74 упражнения, замены, автотесты.

### 3–4 Анкета и UI
Полная анкета, Dashboard, программа, профиль, localStorage.

### 5 Библиотека
Поиск, фильтры, карточки, SVG-схемы.

### 6 Режим тренировки
Таймер отдыха, вес/повторы, история сессий.

### 7 Прогресс и наглядность техники
- График **массы тела** + запись веса
- График **рабочих весов** по упражнениям (выбор упражнения)
- Столбцы тренировок по неделям
- Детальный просмотр сессии (`/progress/[id]`)
- **Анимированные SVG-схемы** по паттерну движения (жим, тяга, присед, наклон…)
- Стрелки направления движения на схеме
- Ссылки **«Видео техники»** → поиск YouTube (RU/EN) из карточки упражнения и режима зала

Видео не встраиваются (нет зависимости от чужого контента и API) — открывается поиск по корректному запросу техники.
