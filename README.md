# Gym Assistant — этапы 1–6

Персональный виртуальный тренер для тренажёрного зала.

## Запуск

```bash
npm install
npm test
npm run typecheck
npm run dev
```

## Реализовано

### 1–2 Ядро
- Детерминированный генератор программ, 74 упражнения, замены, 95 тестов

### 3–4 Интерфейс + анкета
- Полная анкета (пол, тело, уровень, цель, дни, время, оборудование, травмы)
- localStorage, Dashboard, программа с заменой, профиль

### 5 Библиотека
- Поиск, фильтры, карточка упражнения, SVG-схемы

### 6 Режим тренировки
- Экран `/workout?day=N`
- Список упражнений с иллюстрацией и техникой
- Ввод веса и повторений по подходам
- Отметка выполнения подхода
- **Таймер отдыха** (пауза / пропуск, вибрация по окончании)
- Подсказка последнего рабочего веса из истории
- Сохранение черновика сессии (перезагрузка не сбрасывает)
- Завершение → запись в историю
- **Прогресс**: число тренировок, подходов, лучшие веса, лента истории

## Как пользоваться режимом зала

1. Главная или «Моя программа» → «Начать тренировку»
2. Для каждого подхода: вес, повторы → галочка
3. После подхода — таймер отдыха
4. «Завершить» — сессия в «Прогресс»
