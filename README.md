# Gym Assistant — этапы 1–4

Персональный виртуальный тренер. Ядро алгоритма + анкета + интерфейс программы.

## Запуск

```bash
npm install
npm test
npm run typecheck
npm run dev
```

Откройте http://localhost:3000 — при первом запуске откроется анкета.

## Реализовано

### Этапы 1–2
- Детерминированный генератор программ
- 74 упражнения
- Замена упражнений
- 95 автотестов

### Этапы 3–4
- Многошаговая анкета (уровень, цель, дни, длительность)
- localStorage для профиля и программы
- Dashboard с следующей тренировкой
- Экран «Моя программа» с раскрытием упражнений и **заменой**
- Профиль с редактированием и пересчётом программы
- Нижняя навигация (мобильный first)
- Заглушки: Библиотека, Прогресс

## Структура src/

- `lib/` — ядро без React (не трогать без нужды)
- `app/` — страницы App Router
- `components/` — UI
- `hooks/useAppData.ts` — загрузка профиля/плана
