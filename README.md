# Gym Assistant

Персональный виртуальный тренер для тренажёрного зала.

Современное адаптивное веб-приложение (в первую очередь для смартфона): анкета → индивидуальная программа → тренировка в зале → прогресс.

**Стек:** Next.js (App Router) · TypeScript · React · Tailwind CSS · Lucide · localStorage  
**Без** внешних API, платных AI-запросов, регистрации и серверной БД.

---

## Быстрый старт

```bash
npm install
npm test          # автотесты генератора программ
npm run typecheck
npm run dev       # http://localhost:3000
```

Production:

```bash
npm run build
npm start
```

## Деплой на Vercel

1. Создайте репозиторий на GitHub и загрузите проект.
2. [vercel.com](https://vercel.com) → **Add New Project** → Import репозитория.
3. Framework Preset: **Next.js** (определяется автоматически).
4. Build Command: `npm run build` · Output: по умолчанию.
5. **Deploy**. Дополнительные env-переменные не нужны.

Данные пользователя хранятся в `localStorage` браузера — облачная синхронизация в MVP не требуется.

## Что умеет MVP

| Раздел | Возможности |
|--------|-------------|
| **Анкета** | Пол, возраст/рост/вес, уровень, цель, дни, длительность, оборудование, травмы |
| **Генератор** | Детерминированная программа 2–6 дней с учётом уровня, цели, объёма и восстановления |
| **Программа** | Недельный план, замена упражнений, пересчёт при смене профиля |
| **Режим зала** | Рекомендованный рабочий вес с кнопками «−/+», подходы, вес/повторы, таймер отдыха, черновик сессии |
| **Опрос после тренировки** | «Легко/тяжело», «выполнено ли полностью», дискомфорт в суставах → корректировка весов и объёма |
| **Библиотека** | 74+ упражнений, поиск, фильтры, карточка, анимированные схемы, ссылки на видео техники |
| **Прогресс** | История, графики рабочих весов, масса тела, частота тренировок, детали сессии |
| **Профиль** | Редактирование параметров, выбор конкретных дней недели и пересчёт программы |
| **AI Coach (локальный)** | Анализ дневника, подсказки по восстановлению и прогрессии, ответы на типовые вопросы без внешней языковой модели |

## Архитектура `src/lib` (без React)

| Модуль | Назначение |
|--------|------------|
| `config.ts` | Все числовые параметры алгоритма |
| `types.ts` | Типы профиля, плана, сессий |
| `userProfile.ts` | Нормализация и валидация (18+) |
| `exerciseDatabase.ts` | Библиотека упражнений |
| `workoutSplit.ts` | Выбор сплита 2–6 дней |
| `workoutGenerator.ts` | `generateProgram(profile)` |
| `exerciseAlternatives.ts` | Замена по группе и паттерну |
| `loadConfig.ts` | Параметры оценки веса и адаптации (таблица нагрузок, поправки, шаги оборудования) |
| `loadEstimator.ts` | Стартовый рабочий вес по анкете (вес, рост, возраст, пол, уровень, цель, травмы) |
| `progressionEngine.ts` | Двойная прогрессия + опрос: веса и временная коррекция объёма |
| `workoutSession.ts` | Лог подходов и сессии |
| `progressStats.ts` | Агрегация для графиков |
| `storage.ts` | localStorage |
| `coachEngine.ts` | Локальные правила анализа истории и формирования подсказок Coach |

Генератор **детерминирован**: одинаковый профиль → одинаковая программа (порядок массивов в профиле не влияет).

Подробнее об алгоритме — в [docs/ALGORITHM.md](docs/ALGORITHM.md).

### Обновление из предыдущей версии

Замените содержимое проекта целиком файлами из этого архива (не копируйте только `src`). Существующие данные в браузере сохраняются. При первом запуске новая версия автоматически согласует сохранённую программу с выбранными днями недели. Новая функция Coach хранит последние сообщения локально в браузере; сброс данных профиля очищает и эту историю.

## Ограничения MVP

- Нет аккаунтов и облачной синхронизации  
- Coach не является генеративной языковой моделью: ответы формируются локальными правилами и ограничены типовыми темами  
- Нет подписок, Apple Health  
- Видео техники — через поиск YouTube, без встраивания роликов  
- Стартовые веса — грубая оценка по таблице ориентиров, не измерение силы; у тренажёров разные стеки, поэтому для них оценка особенно приблизительна  
- Вес не переносится между разными упражнениями: после замены упражнение снова получает стартовую оценку  
- Объём после опроса только снижается (и возвращается к плану); увеличение объёма — через пересчёт программы  
- Не медицинское изделие: при травмах и заболеваниях нужен специалист  

Архитектура позволяет позже подключить Supabase/PostgreSQL и авторизацию.
